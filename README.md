# Lavendish Super App PWA

Mobile-first Lavendish guest/member app with a premium desktop members portal.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production check

```bash
npm run build
npm start
```

## Included

- PWA manifest + service worker
- Mobile bottom navigation
- Premium responsive desktop member portal layout
- Home, Hotels, Offers, My Stay and Profile
- All 10 Lavendish hotels from the existing website content source used in the earlier rebuild
- One-touch Call / WhatsApp / Book actions
- Hotel search and filters
- Favourites stored locally
- Booking reference saved locally
- Prototype member profile stored locally
- Exact supplied Lavendish logo artwork and exact brand palette
